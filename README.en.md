# GNOME Shell Extension - App Folder Grid Dimensions

[简体中文](README.md) | English

The grid inside GNOME's application folder popup is hardcoded upstream to 3 rows × 3 columns = 9
icons per page. This extension exposes those two numbers as settings, defaulting to 4 rows ×
6 columns = 24 icons. It only adjusts the app folder grid (App Folder Grid) and the popup size; the
launcher grid (App Grid) is unaffected.

## Installation

```sh
git clone https://github.com/luanrz/gnome-shell-extension-app-folder-grid-dimensions.git
cd gnome-shell-extension-app-folder-grid-dimensions
make install
```

After installing, you need to log out and log back in once; then enable it in the Extensions app,
or run the command below:

```sh
gnome-extensions enable app-folder-grid-dimensions@luanrz
```

## Settings

Open this extension's settings window in the Extensions app; you will see two settings, `Rows` and
`Columns`:

| Setting | dconf key | Default | Range | Description                          |
| ------- | --------- | ------- | ----- | ------------------------------------ |
| Rows    | `rows`    | 4       | 3–12  | Rows per page, hardcoded upstream    |
| Columns | `columns` | 6       | 3–12  | Columns per page, hardcoded upstream |

Rows × columns is the grid's capacity per page; the popup size, the cell edge shared by all folders,
and the icon size are all derived from these two numbers and the current screen. When the screen
cannot fit them, the cells and icons in every folder shrink together.
